These questions exercise the graph behind the diagram — gold.fct_appearance joined with gold.dim_book and gold.dim_character. Cortex Analyst writes the SQL; the semantic layer in the dbt project teaches it the cross-book vocabulary (series, pseudonyms, role/alignment).

Example questions

Who is the most-connected character?

Generated SQL

SELECT
    c.name,
    COUNT(*)                          AS book_count,
    LISTAGG(b.title, ', ') WITHIN GROUP (ORDER BY b.published_year)
                                       AS book_list
FROM   gold.fct_appearance a
JOIN   gold.dim_character  c USING (character_sk)
JOIN   gold.dim_book       b USING (book_sk)
GROUP  BY c.name
ORDER  BY book_count DESC
LIMIT  5;

Cortex Analyst response
